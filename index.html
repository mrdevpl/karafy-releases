How it works

1

Pick a file or paste a link

Open an audio or video file you already have, or paste a link — Karafy pulls the audio track automatically.

2

Vocals separated

The track is split into vocals and a clean instrumental — the AI then transcribes the isolated vocal for much better accuracy.

3

AI transcribes & fetches lyrics

Word-level timestamps are generated, then checked against published lyrics to correct mishearings.

4

Lyrics get synced

Each word is aligned to the music. You can preview and fine-tune in the built-in editor.

5

Export in your format

Download KFN with original audio and a "(karaoke)" KFN with clean instrumental — plus LRC, MP4 video, or MP3+G, generated on demand.

A note about the install warning

Karafy is not code-signed yet, so Windows shows a "Windows protected your PC" screen the first time you run the installer. That is Microsoft saying it doesn't recognise the publisher yet — not that anything is wrong with the file. Click More info → Run anyway.

A signing certificate is on the roadmap and will remove the warning. In the meantime every build is published openly on GitHub Releases, so you can check the file yourself before running it.

Frequently asked questions

Which languages does it work with?

The transcription model handles around 100 languages, English and Polish included. Accuracy is best on clear vocals; for anything tricky the built-in editor lets you fix lines by hand.

Do I need a powerful PC or a graphics card?

Any Windows 10/11 machine will run it. A faster CPU mainly means shorter processing times — and if your PC is slow, cloud mode does the heavy lifting instead.

Do I need an internet connection?

Only to fetch the lyrics, and to pull the audio when you start from a link instead of your own file. The transcription and vocal separation run locally on your machine unless you deliberately switch to cloud mode.

What can open a KFN file?

KFN is the format used by KaraFun-compatible players. Karafy also exports MP3+G (CD+G) for karaoke hardware, MP4 for any video player, and LRC for apps that show synced lyrics.

What's the difference between local and cloud?

Local is free and private but bound by your hardware. Cloud is faster, uses larger models and adds AI lyrics correction — it costs credits, and audio is sent to the server for processing only in that mode.

What can I use as the source track?

Any audio or video file on your disk — MP3, WAV, FLAC, M4A, OGG, MP4, MKV — or a link you paste, YouTube included. Whichever you choose, holding the rights to that music is your responsibility; see below.

Can I use the results commercially?

Karafy is a tool — you are responsible for holding the rights to the music you process. For personal and private use it's generally fine; public performance or commercial use needs clearance from the rights holders in your country.

Is there a refund?

Yes — the free tier lets you make 10 songs before paying anything, and if Pro doesn't work for you, email krzysztof@mrdev.pl within 14 days and you'll get your money back.
