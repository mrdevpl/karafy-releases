Windows blocks the Karafy installer

Karafy is not code-signed yet, so Windows does not recognise its publisher. What you do next depends on which message you see.

Haven't bought Karafy yet?

Install the free version first. Your first 10 songs are free, so you can check that Karafy installs on your PC before you pay for anything.

Message 1: "Windows protected your PC"

This is Microsoft Defender SmartScreen, a blue window. It is the common case and takes two clicks:

  1. Click More info.
  2. Click Run anyway.

Message 2: Smart App Control blocked the app

Smart App Control is a Windows 11 security feature, often on by default on new laptops. It blocks apps from publishers it cannot verify, and it has no "Run anyway" button. An unsigned installer can only run if the feature is turned off.

Read this before you turn it off

Smart App Control protects your whole PC, not just this installer. On many versions of Windows it cannot be turned back on without resetting or reinstalling Windows. This is your decision, and keeping it on is a perfectly good choice.

If you decide to turn it off

  1. Open Windows Security.
  2. Go to App & browser control.
  3. Open Smart App Control settings.
  4. Select Off.
  5. Run Karafy-win-Setup.exe again.

If you would rather keep it on

Then Karafy can't be installed on this PC until the installer is signed. If you have already paid, email support@karafy.app within 14 days of purchase and you'll get your money back, as described in our Refund Policy.

How to check your download

Every version is published openly on GitHub Releases, with a SHA-256 checksum next to each file. To compare it with yours, open PowerShell in your Downloads folder and run:

Get-FileHash .\Karafy-win-Setup.exe -Algorithm SHA256

If the two values match, you have the same file we published.

Common questions

Why isn't Karafy signed?

Code signing is planned and will remove these messages. We don't have a date for it yet.

Which Windows versions work?

64-bit Windows 10 and 11. No dedicated graphics card is needed.

I've installed it. How do I activate my licence?

Open Karafy and click Pro / License in the top right. Paste your key from the purchase email into the License key field and click Activate key.
